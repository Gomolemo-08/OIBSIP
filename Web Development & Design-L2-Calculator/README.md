# Glass Calculator

Vanilla HTML, CSS and JavaScript calculator. No libraries, no eval().

## Run
Open `index.html` in any browser.

## Files
- index.html: markup
- style.css: glassmorphism styles, light/dark themes, CSS Grid keypad
- script.js: custom expression evaluator, keyboard support, history, theme toggle

## Features
Operator chaining with precedence, division-by-zero error, backspace, clear, %, +/-, calculation history (localStorage), dark/light mode, keyboard input.
