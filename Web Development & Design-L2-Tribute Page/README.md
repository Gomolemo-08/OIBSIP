# Marie Curie · Tribute Page

HTML5 + CSS3 + a little vanilla JavaScript.

## Run
Open `index.html` in a browser (internet needed for images and fonts).

## Structure
- index.html: content and layout
- css/style.css: design system, timeline, cards, gallery, responsive rules
- js/script.js: scroll animations, mobile menu, lightbox

## Credits
Images: Wikimedia Commons (public domain). Text: original, paraphrased from public references (Britannica, NobelPrize.org).
Fonts: Playfair Display (headings) and Inter (body) from Google Fonts.
